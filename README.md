# NASA Engine Failure Analysis

## Objective
Predict Remaining Useful Life (RUL) of aircraft engines.

## Dataset
NASA CMAPSS FD001

## Workflow

1. Data Understanding
2. Exploratory Data Analysis
3. Statistical Analysis
4. PCA Health Index
5. Root Cause Analysis
6. Machine Learning Prediction

## Results

MAE: 11 cycles

R² Score: 0.943

## Key Failure Drivers

- Sensor 11
- Sensor 4
- Sensor 15

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
